Contributing to AutoGamePlayer

Thank you for your interest in contributing to AutoGamePlayer.

AutoGamePlayer is a modular Android-first automation platform for games owned or controlled by the project developer. Contributions that improve the core architecture, supported game modules, testing, documentation, reliability, and performance are welcome.

Before Contributing

Please:

1. Read the README.
2. Understand the project architecture.
3. Check existing issues and pull requests before starting substantial work.
4. Keep changes focused and related to the purpose of the project.
5. Do not introduce code intended to bypass anti-cheat, DRM, authentication, access controls, or other protections of third-party games.

Reporting Issues

When reporting a bug, include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected behavior.
- Actual behavior.
- Relevant logs or error messages.
- Android/device information when relevant.

Pull Requests

Before opening a pull request:

- Explain what the change does.
- Keep the pull request focused.
- Add or update tests when appropriate.
- Update documentation when behavior or public interfaces change.
- Make sure existing tests continue to pass.

Code Quality

Prefer:

- Small, focused changes.
- Clear naming.
- Reusable interfaces.
- Separation between the core engine and game-specific logic.
- Testable behavior.
- Documentation for important architectural decisions.

Review Process

Pull requests may be reviewed for correctness, maintainability, testing, documentation, and compatibility with the project's architecture.

Thank you for helping improve AutoGamePlayer.
