Security Policy

Supported Versions

AutoGamePlayer is currently under active development.

Security fixes are prioritized for the latest development version of the project.

Reporting a Vulnerability

Please do not disclose security vulnerabilities through a public GitHub issue.

When reporting a security vulnerability, provide:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Affected component or file, if known.
- Relevant logs or proof of concept, where safe to provide.
- Any suggested mitigation, if available.

Use the repository maintainer's available private GitHub contact or security reporting mechanism for sensitive reports.

Scope

Security reports may include issues involving:

- Application security
- Authentication or authorization
- Unsafe handling of sensitive data
- Insecure configuration
- Dependency vulnerabilities
- Code execution or privilege escalation
- Security-sensitive automation behavior

Out of Scope

The project does not intentionally support bypassing:

- Anti-cheat systems
- DRM
- Authentication controls
- Access controls
- Security protections of third-party games

Reports about bypassing such protections are outside the intended scope of the project.

Disclosure

Please allow reasonable time for a vulnerability to be investigated and addressed before publicly disclosing details.

Thank you for helping keep AutoGamePlayer secure.
